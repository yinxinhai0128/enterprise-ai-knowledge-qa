## 二、各系列定位与目标人群

### 2.1 Cloud Luxe 云奢系列

- 定位：旗舰高端线，酒店级触感的日常化
- 目标人群：追求顶级睡眠体验的成熟消费者、礼赠场景（乔迁、婚礼）
- 关键卖点：600TC 埃及长绒棉，丝滑光泽，耐洗耐用
- 关联文档：材质细节见《04-材质详解与性能对比》

### 2.2 Bamboo Breeze 竹风系列

- 定位：功能型睡眠解决方案（吸湿排汗）
- 目标人群：易出汗人群、过敏体质、热带/夏季使用需求
- 关键卖点：天然抗菌、透气性优于棉
- 注意：美国市场标签按 FTC 要求标注（见《04》竹纤维小节）

### 2.3 Pure Organic 纯有机系列

- 定位：健康与可持续消费首选
- 目标人群：婴儿家庭、敏感肌人群、环保主义者
- 关键卖点：GOTS 认证（证书 CU12345678），无农药化肥转基因种子

### 2.4 Cool Touch 凉感系列

- 定位：一觉到天亮的控温体验
- 目标人群：怕热人群、盗汗困扰者；日本市场主推
- 关键卖点：天丝纤维的吸湿快干与丝滑触感

### 2.5 Flannel Cozy 法兰绒系列

- 定位：秋冬保暖刚需
- 目标人群：北美、加拿大、北欧寒冷地区用户
- 关键卖点：拉绒工艺带来的柔软绒面与锁温性

### 2.6 Hotel Collection 酒店系列

- 定位：B2B 批发主线，耐用优先
- 目标人群：酒店、民宿、医院、大学宿舍等机构采购（详见《11-B2B批发与企业采购》）
- 关键卖点：棉涤混纺耐商用洗涤，250TC 高性价比

### 2.7 Kids Cloud 儿童系列

- 定位：儿童房安心之选
- 目标人群：有婴幼儿及学龄儿童的家庭
- 关键卖点：OEKO-TEX 认证纯棉，符合美国儿童纺织品可燃性标准（16 CFR Part 1610）

## 三、产品品类构成

**床品套装（Bedding Sets）**
- 四件套：被套 1 + 床单 1 + 枕套 2
- 三件套：被套 1 + 枕套 2（不含床单）
- 五件套：被套 1 + 床单 1 + 枕套 2 + 抱枕套 1
- 单品：被套、床单、枕套可单独购买

**枕芯（Pillows）**
- 羽绒枕：95% 白鸭绒填充，500 蓬松度
- 记忆棉枕：50D 慢回弹，高低可调
- 竹纤维枕：透气抗菌，适合过敏人群
- 侧睡枕 / 仰睡枕（专门设计）

**被芯（Comforters / Duvets）**
- 羽绒被：90% 白鹅绒，600 蓬松度，All-Season / Winter 两款
- 替代羽绒被（Alternative Down）：不含动物成分，适合素食主义者
- 四季被：春秋薄被 + 冬季厚被可通过纽扣组合

**床垫保护垫（Mattress Protectors）**
- 防水款：TPU 防水层，100% 棉表面——适合儿童床、有宠物家庭
- 透气款：竹纤维表面，无防水涂层——适合注重舒适度的成人
- 深兜适配：标准 6–12 英寸 / 深兜 12–18 英寸 / 超深兜 18–24 英寸（详见《03-尺寸规格对照》）

**毛巾浴巾（Towels）**
- 浴巾（Bath Towel）：700GSM 埃及棉
- 手巾（Hand Towel）、方巾（Washcloth）
- 浴袍（Bath Robe）：华夫格款、毛圈款

## 四、SKU 命名规则

格式：`[系列缩写]-[品类]-[颜色代码]-[尺寸代码]`

示例：`CL-SET4-WT-QN` = Cloud Luxe 系列 / 四件套 / 白色 / Queen 尺寸

| 字段 | 取值说明 |
|------|---------|
| 系列缩写 | CL（Cloud Luxe）、BB（Bamboo Breeze）、PO（Pure Organic）、CT（Cool Touch）、FC（Flannel Cozy）、HC（Hotel Collection）、KC（Kids Cloud） |
| 品类代码 | SET4（四件套）、SET3（三件套）、SET5（五件套）、DS（被套）、FS（床单）、PS（枕套）、PW（枕芯）、CM（被芯）、MP（床垫保护垫）、TW（毛巾）、RB（浴袍） |
| 颜色代码 | WT（白色）、GY（灰色）、BL（蓝色）、GR（绿色）、PK（粉色）、NV（藏青）、BG（米色）等，以商品页为准 |
| 尺寸代码 | T/TXL/F/Q/K/CK 对应北美尺寸；EU 系列以厘米标注 |

**客服提示**：客户报 SKU 时按上表拆解即可快速定位产品；SKU 中颜色或尺寸代码超出上表时，以商品页详情为准并如实告知。

## 五、各系列高频问答

### 5.1 Cloud Luxe 云奢系列 FAQ

Q：云奢系列为什么贵？
A：600TC 埃及长绒棉（纤维 ≥36mm），纱线细、织造密度高，成本主要在原料与工艺；同档国际品牌定价通常更高。

Q：云奢和酒店系列手感差在哪？
A：云奢 600TC 长绒棉更丝滑、有光泽；酒店系列 250TC 棉涤混纺偏挺爽耐用，为商用高频洗涤设计。

Q：云奢会起球吗？
A：长绒棉正常洗涤不应明显起球；请按《05》冷水翻面洗涤。若明显起球属质量问题，可走质保。

Q：送礼选什么颜色稳妥？
A：白色（WT）与米色（BG）最百搭；礼盒包装服务见本章第六节。

### 5.2 Bamboo Breeze 竹风系列 FAQ

Q：竹纤维是纯竹子做的吗？
A：混纺比例 60% 竹纤维 + 40% 棉；美国市场标签按 FTC 要求规范标注（《04》第二节）。

Q：夏天睡真的凉快吗？
A：竹纤维吸湿排汗性能优于棉，适合易汗人群；但"凉感"体感因人而异，可参考《04》对比表。

Q：可以用消毒液洗吗？
A：不建议含氯漂白剂（损伤纤维）；如需除菌建议按《05》低温洗涤+充分晾晒。

### 5.3 Pure Organic 纯有机系列 FAQ

Q：怎么确认是真有机棉？
A：GOTS 证书编号 CU12345678 可在 global-standard.org 官网核查；每件产品的吊牌也有 GOTS 标识。

Q：有机棉会不会更容易皱？
A：有机棉未经化学防皱处理，褶皱略多于普通棉；熨烫中温 130°C 即可平整。

Q：宝宝能用吗？
A：可以——无农药化肥残留、亲肤哑光；婴幼儿床品另可选 Kids Cloud 儿童系列。

### 5.4 Cool Touch 凉感系列 FAQ

Q：天丝和真丝一样吗？
A：不一样。天丝（Lyocell）是木浆再生纤维素纤维，触感丝滑但价格远低于真丝，且可机洗（30°C 以下）。

Q：凉感能持续多久？
A：天丝的吸湿速干是纤维固有属性，不依赖涂层，多次洗涤后依然有效。

Q：日本客户常问的クイーン尺寸有货吗？
A：凉感系列覆盖日本市场，尺寸对照《03》第三节。

### 5.5 Flannel Cozy 法兰绒系列 FAQ

Q：法兰绒会掉毛吗？
A：拉绒工艺初期有轻微浮毛，洗涤几次后消失；首次洗涤轻微掉色亦属正常（《04》第五节）。

Q：南方冬天没暖气够暖吗？
A：170–200 GSM 法兰绒锁温性良好；搭配白鹅绒被芯保暖更佳。

### 5.6 Hotel Collection 酒店系列 FAQ

Q：自用买酒店系列划算吗？
A：划算——250TC 棉涤混纺耐用耐洗，价格 $29–$69；但手感和高端系列有差距，追求体验选 Cloud Luxe。

Q：批量采购找谁？
A：wholesale@cloudcottonhome.com；折扣梯度与流程见《11》。

### 5.7 Kids Cloud 儿童系列 FAQ

Q：儿童系列的安全标准是什么？
A：符合美国 CPSC 16 CFR Part 1610 纺织品可燃性标准；OEKO-TEX 认证纯棉。

Q：和成人系列的区别只是尺寸吗？
A：不止尺寸——面料选择、染料安全性按儿童纺织品标准执行；图案设计面向儿童房场景。

## 六、新品上市与生命周期

### 6.1 新品上市节奏

- 新品从打样到上架周期约为 2–3 个月（示例口径）
- 上架前经质检（参照 ISO 9001:2015 体系）与合规检测
- 新品信息以官网商品页为准；客服在官网公布前不得提前承诺发售时间

### 6.2 断货与停产政策

- 断货 SKU 在商品页标注补货时间（能确定时）；无法确定时客服如实告知并推荐替代款
- 套装中单品断货时：可整单延迟发货、或拆分发货、或更换等价单品（需客户确认）
- 停产款式不再补货，库存售罄即下架；停产款不影响已购客户的 180 天质量保证

## 七、礼盒包装服务

- 适用场景：节日礼品、婚礼乔迁赠礼
- 内容：定制礼盒 + 贺卡（可留言）+ 礼品收据（不含价格）
- 费用：部分活动期免费（如情人节、母亲节套装），常规期收费以结账页显示为准
- 注意：使用礼盒包装的订单同样适用 30 天退换政策，但外包装需完好（《07》）

## 九、套装与单品购买策略

### 9.1 套装 vs 单品的价差逻辑

| 购买方式 | 构成 | 价格特点 |
|---------|------|---------|
| 四件套 | 被套+床单+枕套×2 | 比单买省约 15–20%（示例口径，以商品页为准） |

| 五件套 | 四件套+抱枕套 | 礼赠场景首选 |
| 单品 | 任意单独购买 | 补货/换风格灵活 |

### 9.2 混搭建议（客服推荐话术）

- 预算充足：直接四件套一步到位

- 租房过渡：酒店系列单品自由组合，搬家丢弃不心疼

## 十、颜色体系说明

### 10.1 常设色卡

| 代码 | 颜色 | 特点 |
|------|------|------|
| WT | 白色 | 经典酒店感；显干净但需勤洗 |
| BG | 米色 | 温暖百搭；耐脏度中等 |
| GY | 灰色 | 现代简约；深浅灰随批次可能略有色差 |
| BL | 蓝色 | 主卧常见；冷色调助眠联想 |
| NV | 藏青 | 深色系代表——首次洗涤浮色明显（《05》），需单独洗 |
| GR/PK | 绿/粉 | 季节限定色居多，售罄不一定补 |

### 10.2 色差问题的标准应答

- 屏幕显示 vs 实物存在 ±5–10% 色差属正常范围（《原文档》十六）
- 深色系（NV/深灰/墨绿）色差感知更明显
- 差异"明显"的判定：与官网同款图并排对比显著不同 → 按颜色差异走售后（《12》赔偿表）
- 批次间轻微色差：纺织品正常现象；介意者下单前可咨询当前批次

## 十一、限定款与联名

- 季节限定（圣诞图案、春季花卉等）售完即止，通常不补货
- 联名/合作款以官方公告为准；客服在公告前不得确认任何未发布合作
- 限定款的售后政策与常规款一致（《07》）——限定身份不免除或不放宽退换条件

## 十二、库存状态查询指引

客户问"XX 还有没有货"时的处理：

1. 引导查看商品页库存标识（Add to Cart 可点即有货）
2. 页面可下单但下单时提示缺货：极少数并发场景，客服核实后协助取消或转预售
3. 断货 SKU 的补货通知：商品页 Subscribe 按钮，到货自动邮件
4. 客服**不承诺具体补货日期**——供应链信息未同步前一切口头时间都不可信；只说"已登记，到货会第一时间通知"
