# 11 · B2B 批发与企业采购

> 本文档供 B2B 销售与客服团队查询批发客户类型、折扣梯度、定制服务、账期条款与合规文件要求使用。酒店/民宿/机构客户的采购咨询依据本文档作答。

---

## 一、B2B 客户类型

- 酒店 / 民宿（Hotel & Airbnb）
- 医院 / 养老院
- 大学宿舍
- 室内设计公司
- 零售商 / 分销商
- 企业福利采购

## 二、批发折扣梯度（Hotel Collection 系列）

| 采购数量 | 折扣 |
|---------|------|
| 50–199 件 | 8 折（20% off） |
| 200–499 件 | 7 折（30% off） |
| 500–999 件 | 6.5 折（35% off） |
| 1000 件以上 | 6 折（40% off），支持定制 LOGO |

其他系列批发价格请联系 wholesale@cloudcottonhome.com 获取报价单。

## 三、样品政策（补充说明）

以下为示例政策，具体以报价单为准：

| 项目 | 说明 |
|------|------|
| 样品下单 | 按 Hotel Collection 全价购买样品 |
| 样品抵扣 | 正式批量下单后，样品费用在首单发票中抵扣（上限为样品实付金额） |
| 样品组合 | 提供面料小样（swatch）免费寄送，成品样品需付费 |
| 寄送时效 | 面料小样 3–5 工作日；成品样品随正常订单时效（《06》） |

**客服话术要点**：客户犹豫是否大批量采购时，先引导走样品流程验证品质，再谈量价梯度。

## 四、定制服务

- 刺绣（Embroidery）：支持 LOGO 刺绣、姓名首字母刺绣
- 颜色定制：≥500 件可定制 Pantone 颜色
- 包装定制：定制礼盒、挂牌、织唛（仅 B2B 客户）
- 交期：定制订单 30–45 天

注意：定制款（刺绣姓名、定制颜色）无质量问题时不支持退货（《07》第三节）；B2B 定制订单请在合同中明确验收标准。

## 五、账期与付款

- 首单全款预付
- 长期合作客户（交易满 6 个月 / $50,000+）可申请 Net 30 账期
- 支持电汇（TT）、信用证（LC）、PayPal 商业版

### 5.1 贸易术语说明（供参考）

| 术语 | 含义 | 适用场景 |
|------|------|---------|
| FOB（Free On Board） | 卖方负责到装运港的费用与风险，海运段及之后由买方承担 | 大宗出口、买方指定货代 |
| CIF（Cost, Insurance & Freight） | 卖方承担运费+保险到目的港，风险仍在装运港转移 | 买方希望简化物流安排 |
| DDP（Delivered Duty Paid） | 卖方负责全程运输、关税，送达指定地点 | 买家只想收货不想管清关 |

以上为通俗解释，实际交易以合同约定为准；跨境零售订单不适用上述术语（见《06》清关说明）。

## 七、B2B 常见问答

**Q：混批不同系列能享受梯度折扣吗？**
A：折扣梯度基于 Hotel Collection 系列数量计算；其他系列批发价单独报价。

**Q：酒店项目分期施工、分批交货可以吗？**
A：支持分批交货；折扣按合同总量锁定，分批开票结算。定制部分交期 30–45 天。

**Q：大学宿舍采购有教育优惠吗？**
A：宿舍采购归入机构客户，按批发梯度执行；Twin XL 尺寸备货充足（《03》）。

## 八、B2B 合作全流程

```text
询盘 → 报价 → 打样确认 → 合同签订 → 大货生产 → 质检出货 → 物流交付 → 对账售后
```

| 阶段 | 动作 | 时效参考 |
|------|------|---------|
| ① 询盘 | 客户邮件至 wholesale@cloudcottonhome.com，说明品类/数量/交期 | 销售团队 1 个工作日内响应 |
| ② 报价 | 按数量梯度出具报价单（含价格/交期/贸易术语） | 2–3 工作日 |
| ③ 打样 | 成品样品寄送（全价购买、首单抵扣——《11》第三节） | 面料小样 3–5 工作日；成品随订单时效 |
| ④ 签约 | 明确验收标准、交期、付款方式（首单预付） | 双方协商 |
| ⑤ 生产 | 现货直接排单；定制生产 30–45 天（《11》第四节） | — |
| ⑥ 质检 | 出货前按 ISO 9001:2015 体系抽检；可约定第三方验货 | — |
| ⑦ 交付 | 按合同贸易术语交付（FOB/CIF/DDP 解释见第五节） | 视目的地 |
| ⑧ 售后 | B2B 售后走对公流程（本章第十节） | — |

## 九、报价单字段说明

客户拿到报价单后常问的字段：

| 字段 | 含义 |
|------|------|
| Unit Price | 单件价格（按梯度折扣后） |
| MOQ | 最小起订量：Hotel Collection 系列 50 件起 |
| Lead Time | 从定金到发货的生产周期 |
| Payment Terms | 付款条件：首单 T/T 全款预付；老客户可申请 Net 30 |
| Validity | 报价有效期（通常 15–30 天，原材料波动时缩短） |
| Incoterms | 交货条款（FOB/CIF/DDP，见《11》第五节） |

**客服提示**：报价解释类问题转 B2B 组；不要替销售口头承诺价格。

## 十、B2B 售后差异（对公流程）

| 差异点 | B2B 做法 | 与零售的区别 |
|--------|---------|-------------|
| 质量异议 | 到货后 X 日内书面提出并附验货报告（合同约定） | 不走个人 30 天退货 |
| 退款路径 | 对公账户原路退回（T/T），周期按合同 | 零售退原支付方式 |
| 补货换货 | 按合同补足次品率超出部分 | 零售按单件处理 |
| 专属支持 | B2B 组客户经理对接 + 优先工单通道 | 零售走通用客服 |

180 天质量保证同样适用于批发产品；批量质量问题的赔偿方案以合同索赔条款为准，《12》赔偿表作为零售口径参考。

## 十一、酒店项目合作要点

- **常见需求组合**：床品四件套 + 保护垫 + 浴巾浴袍的整房配置
- **翻新周期**：酒店通常按季度/半年度分批补采
- **LOGO 刺绣**：1000 件以上免费（《11》第二节）；打样确认绣样后再大货
- **案例模板**（应答参考）：某连锁民宿 200 间房——HC 四件套×400 套（7 折档）+ 防水保护垫×400，DDP 条款分两批交付
- 具体项目报价一律由 B2B 销售出具，客服只做流程引导与文档查询

## 十二、B2B 高频问答

Q：我们是 Airbnb 房东，一次买 20 套有折扣吗？
A：未达 50 件起订量；可先按零售价下单，累计或凑单到 50+ 后联系 wholesale 重新议价。

Q：可以开发票抬头给我们的管理公司吗？
A：可以，按《08》第九节提供企业信息；跨境对公交易由财务出具形式发票（PI）。

Q：定制颜色最小起订量？
A：Pantone 定制色需 ≥500 件（《11》第四节）；刺绣 LOGO 无单独起订量限制（随批量折扣档执行）。

## 十三、B2B 与零售的边界判定

客户咨询时先判定身份归属：

| 信号 | 归属 |
|------|------|
| 单笔 <50 件、个人账户下单 | 零售流程（《07》全套适用） |
| 明确以机构名义采购 ≥50 件 | B2B 流程，转 wholesale 邮箱 |
| 设计师代客采购 | 视数量：不足 MOQ 走零售，可留联系方式给 B2B 组跟进 |
| 二手转卖商 | 需 B2B 审核（品牌方对渠道有管理权） |

**客服提示**：不要替 B2B 组报价或承诺交期；做好信息收集（公司名/品类/数量/期望交期）并转交即可。

## 十四、B2B 文件流转时效参考

| 文件 | 出具方 | 时效 |
|------|--------|------|
| 报价单 | B2B 销售 | 2–3 工作日 |
| 形式发票 PI | 财务 | 收到订单确认后 1–2 工作日 |
| 合规文件包 | 合规部 | 3–5 工作日 |
| 出货单据（B/L 等） | 物流+财务 | 按合同贸易条款 |

以上为内部参考时效，对外承诺以合同为准。

## 十五、B2B 常见异议应对（销售支持口径）

- "竞品更便宜" → 引导对比认证背书（OEKO-TEX/GOTS/RDS）与商用耐洗设计；价格战不跟
- "MOQ 太高" → 说明 50 件是折扣梯度门槛而非生产门槛；可先样品后放量
- "交期能不能压缩" → 定制 30–45 天为工艺底线；现货系列可谈分批先行交付
- "要独家代理" → 转商务团队评估，客服不做任何区域授权承诺

## 十六、B2B 客户分层服务标准（内部参考）

| 层级 | 定义 | 服务标准 |
|------|------|---------|
| Key Account | 年采购 ≥$50,000 | 专属客户经理 + 季度业务回顾 + Net 30 默认资格 |
| Growth | 年采购 $10,000–$50,000 | 共享客户经理 + 新品优先试用 |
| SMB | 首单至 $10,000 | 标准流程支持 + 邮件响应 |

层级评定每年一次；升降级邮件通知，不影响已签合同的条款。

## 十七、B2B 数据与隐私边界

- B2B 合同中的价格条款互相保密——不得向 A 客户透露 B 客户的折扣
- 客户提供的住客数据（如刺绣名单）仅用于履约，用后按约定销毁
- 涉及个人数据的定制订单（姓名刺绣）：生产完成后名单文件即删除

```text
客户问"批量买有折扣吗？"
```
