# 05 · 洗涤护理指南

> 本文档供客服团队指导客户正确洗涤与保养产品使用。客户咨询"能不能机洗""怎么洗不缩水""羽绒被怎么存""洗坏了怎么办"时依据本文档作答。

---

## 一、通用洗涤原则

- 首次使用前建议水洗一次，去除出厂浆料
- 使用中性、无荧光增白剂的洗涤液
- 深色产品建议单独洗涤，避免褪色染色其他衣物
- 避免使用含氯漂白剂（会损伤纤维并加速褪色）
- 洗涤后充分漂洗，避免残留洗涤剂
- 被套和被芯分开洗，确保彻底清洁和烘干；被芯（尤其羽绒被）需大容量洗衣机，建议去洗衣房用商用洗衣机

## 二、分材质护理速查表

| 材质 | 水洗温度 | 烘干 | 熨烫 | 干洗 |
|------|---------|------|------|------|
| 埃及棉 | 冷/温水 ≤40°C | 低温可烘干 | 中温（130°C） | 不建议 |
| 竹纤维 | 冷水 ≤30°C | 低温/阴干 | 低温（110°C） | 可 |
| 天丝/Tencel | 冷水 ≤30°C | 低温/阴干 | 低温（110°C） | 可 |
| 有机棉 | 冷/温水 ≤40°C | 低温可烘干 | 中温（130°C） | 不建议 |
| 法兰绒 | 冷水 ≤30°C | 低温烘干 | 不建议 | 不建议 |
| 羽绒被芯 | 温水 ≤40°C，大容量洗衣机 | 低温+烘干球 | 不适用 | 可 |
| 记忆棉枕 | 不可整体水洗，点洗枕套 | 不适用 | 不适用 | 不适用 |

## 三、羽绒产品专项护理

- 洗涤时加入 3–4 个干净网球或烘干球，防止羽绒结块
- 烘干需彻底（至少 2–3 个循环），未烘干的羽绒产品会产生异味或发霉
- 存放时使用透气棉袋，不可长期压缩存放（损伤蓬松度）
- 建议每 2–3 年专业清洗一次

## 四、枕芯更换周期

| 枕芯类型 | 建议更换周期 | 判断标准 |
|---------|------------|---------|
| 羽绒枕 | 2–3 年 | 折叠后无法回弹、有异味、变形严重即需更换 |
| 记忆棉枕 | 3–5 年 | 同上 |
| 纤维枕（涤纶） | 1–2 年 | 同上 |

## 五、常见误洗场景与补救

### 5.1 缩水

- 正常现象：棉类首次水洗有 3–5% 自然缩水，制作时已预留缩水量，洗后尺寸为标准销售尺寸
- 超标缩水（>5%）：请客户提供测量数据与照片，联系客服按质量问题处理（《07-退换货与退款政策》）

### 5.2 起球

- 高发对象：短绒棉或低 TC 产品
- 预防：冷水、翻面洗涤、洗衣袋保护
- 补救：可用织物去球器轻除；长绒棉产品正常洗涤不应明显起球，明显起球属质量问题可申请售后

### 5.3 串色 / 褪色

- 正常现象：深色产品前 2–3 次洗涤有轻微浮色
- 补救（串色发生时）：立即停用洗衣机，用冷水 + 中性洗涤剂单独重洗受染衣物；顽固串色可用彩色衣物专用去色渍片（按说明书）
- 大量褪色：提供照片联系客服申请退换

### 5.4 羽绒结块 / 异味

- 成因：烘干不彻底导致羽绒受潮结块
- 补救：重新低温烘干 2–3 个循环并加入烘干球；仍无法恢复蓬松且有霉味的，按质量问题联系客服

### 5.5 常见技术问答

**Q：新产品有异味怎么办？**
A：轻微仓库气味水洗后即消失；气味强烈或异常请联系客服，属质量问题可申请退换。

**Q：可以同时洗被套和被芯吗？**
A：不建议。被套和被芯分开洗；被芯需商用大容量洗衣机（见第一节）。

**Q：毛巾浴巾怎么洗才蓬松？**
A：700GSM 埃及棉毛巾避免使用柔顺剂（柔顺剂会在纤维表面成膜降低吸水性），低温烘干或晾干后抖散绒毛即可恢复蓬松。

## 六、污渍处理速查表

| 污渍类型 | 应急处理 | 注意事项 |
|---------|---------|---------|
| 咖啡/茶渍 | 冷水冲洗 + 中性洗涤剂揉洗 | 热水会让蛋白质类污渍固化 |
| 血渍 | **冷水** + 加酶洗衣液浸泡 30 分钟 | 热水使血渍蛋白凝固，越洗越牢；生理期床单常见 |
| 油渍（护肤品/食物油） | 干纸巾按压吸油 → 餐具洗洁精预涂 → 温水洗 | 不要先碰水；硅油类（护发精油）最难洗，需二次预涂 |
| 墨水/圆珠笔 | 酒精棉球从污渍外围向中心拍 | 用发胶/酒精前先在边角试色 |
| 果汁/红酒 | 立即撒盐吸附 → 冷水 + 氧净（含氧漂白） | 含氯漂白剂禁用（《05》第一节） |
| 尿渍（儿童/宠物） | 冷水冲洗 + 加酶洗衣液 + 充分晾晒 | 防水保护垫是根本解法（《02》保护垫防水款） |
| 化妆品（粉底/口红） | 卸妆油局部乳化 → 洗洁精去油 → 正常洗 | 先卸妆再下水 |

**通用原则**：污渍处理黄金时间是 24 小时内；处理失败留下痕迹的，不影响按正常售后流程判定（未成功去除的预处理不算"已使用"的拒保理由——但已机洗烘干的按正常流程判定）。

## 七、洗衣机类型建议

| 洗衣机类型 | 适合 | 不适合 |
|-----------|------|--------|
| 滚筒（家用 8kg+） | 被套、床单、枕套、毛巾 | 大号羽绒被芯（容量不足洗不透） |
| 波轮（家用） | 床品四件套、法兰绒 | 天丝类易缠绕起皱，选轻柔档 |
| 投币/商用大滚筒 | 羽绒被芯、大尺寸 King/CK 被芯 | — |
| 手洗 | 记忆棉枕套点洗、局部污渍 | 全部大件（拧不干） |

## 八、换季收纳指南

### 8.1 收纳前

- **必须彻底洗净并烘干**：残留汗渍油脂会发黄霉变；羽绒被未彻底烘干会霉变结块（《05》第三节）
- 法兰绒收纳前确认无浮色风险（首次洗涤后）

### 8.2 收纳中

- 羽绒被：透气棉袋存放，禁止真空压缩袋（长期压缩损伤蓬松度，影响保暖）
- 棉类：折叠平放于干燥柜格；放樟脑丸需隔层包裹避免直接接触面料
- 天丝/竹纤维：避光存放（长期暴晒褪色）

### 8.3 出柜复用

- 取出后通风晾晒半天再使用
- 有霉点：轻度霉点用棉布蘸稀释酒精擦拭后晾晒；大面积霉变属存放不当，不适用质量保证

## 九、分材质补充 FAQ

Q：埃及棉四件套多久洗一次合适？
A：贴身使用的被套枕套建议 1–2 周一次；床单可 2–4 周。过频洗涤加速磨损，过疏积累皮脂。

Q：深色和浅色可以一起洗吗？
A：前 3 次洗涤务必分开（浮色期）；之后同色系深浅可同洗。

Q：烘干机会不会把被子烘坏？
A：低温档+烘干球不会；高温档会导致缩水与纤维脆化。羽绒被必须彻底烘干（2–3 个循环）。

Q：酒店系列能用工业洗涤吗？
A：可以。250TC 棉涤混纺就是为商用高频洗涤设计的；建议遵循工业洗涤温度 ≤60°C。

Q：毛巾发硬怎么办？
A：通常是柔顺剂残留或硬水矿物质沉积——用一杯白醋替代柔顺剂空洗一轮，再正常烘干即可恢复蓬松（《05》毛巾问答）。

Q：枕套上的防晒霜印子怎么去掉？
A：属油性残留：餐具洗洁精预涂揉洗，再正常机洗；顽固残留重复两次。

## 十、洗涤标签符号解读（对客教学）

国际通用洗护标签五类符号：

| 符号类别 | 含义 | 我司常见标注 |
|---------|------|-------------|
| 水洗槽 | 温度上限与机洗档位 | 30°C/40°C、轻柔档横线 |
| 三角形 | 漂白规则 | 叉 = 禁止漂白（全线产品默认禁氯漂） |
| 方块 | 烘干规则 | 圆点=温度档；叉 = 不可烘干（天丝常见） |
| 熨斗 | 熨烫温度 | 1 点 110°C / 2 点 130°C / 叉 = 不可熨 |
| 圆圈 | 干洗规则 | P = 可干洗；叉 = 不可干洗 |

客户问"标签上的圆圈里有个P是什么意思"→ 可干洗，常规四乙烯干洗剂。

## 十一、硬水地区洗涤补充

美国部分地区与德国部分老建筑为硬水：

- 现象：毛巾越洗越硬、白色面料发灰
- 原因：钙镁离子与洗涤剂结合沉积在纤维上
- 对策：每 4–6 周用一杯白醋空洗一次（溶解沉积）；洗涤剂用量按硬水档多加 20%
- 客户问"是不是质量变差了"：先排查硬水因素再谈售后

## 十二、宠物家庭专项

- 毛发清理：烘干后用粘毛滚筒比水洗前处理更高效
- 抓痕/勾丝：人为损坏范围（《07》第十二节），不在质保内——下单前主动推荐防水保护垫 + 耐用款酒店系列
- 尿液事故：防水保护垫是根本解法；已渗入床垫的按污渍速查表处理并充分晾晒

## 十三、洗涤频率建议总表

| 产品 | 建议频率 |
|------|---------|
| 被套/枕套 | 1–2 周 |
| 床单 | 2–4 周 |
| 羽绒被芯 | 外罩勤洗；芯体 2–3 年专业清洗一次 |
| 保护垫 | 1–2 月（防水款表面擦拭为主） |
| 毛巾浴巾 | 使用 3–4 次后 |
| 法兰绒（冬季） | 季初季末各一次 + 视情况 |

## 十五、洗护类高频误判澄清（售后判定参考）

| 客户主张 | 事实核查点 | 判定倾向 |
|---------|-----------|---------|
| "洗一次就缩水了，质量问题！" | 棉类首次缩水 3–5% 已预留；>5% 才超标 | 常规现象除非超标 |
| "起球了，是假货吧" | 起球与纤维长度/洗涤方式相关 | 长绒棉正常洗护不起球→查洗涤方式 |
| "晒完被子有味道" | 羽绒晒后绒腥味加重属正常 | 通风散味即可 |
| "毛巾用两周就硬了" | 多为硬水/柔顺剂沉积 | 白醋空洗方案（《05》第十一节） |
| "新被子有味道" | 出厂包装气味，通风可散 | 强烈异味才走质量流程（《05》） |

判定纪律：先核查事实（洗涤方式/水质/使用时长），再引用对应条款；不预设客户有错。

## 十七、洗涤服务与第三方护理（边界说明）

- 我司**不提供**付费洗涤/翻新服务——客户问"能不能寄回来帮我洗"如实告知
- 第三方干洗店建议：羽绒制品选有羽绒护理经验的店家（普通干洗剂残留会影响蓬松）
- 记忆棉枕不可干洗（溶剂腐蚀发泡体）；只能外壳点洗+通风
- 因第三方护理造成的损坏不在质保范围（《07》第十二节精神延伸）
