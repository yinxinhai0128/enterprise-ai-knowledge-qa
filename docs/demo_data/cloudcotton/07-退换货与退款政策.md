# 07 · 退换货与退款政策

> 本文档供客服团队处理退换货申请使用。客户咨询"能不能退""怎么换货""退款多久到账""亚马逊买的怎么退"时依据本文档作答。所有时限与条件为硬性政策，客服不得口头放宽。

---

## 一、退货政策（独立站）

- 退货期限：**自收货之日起 30 天**内可申请退货
- 条件：产品须为**未洗涤、未使用、原包装**状态
- 退货运费：
  - 质量问题：云棉家居承担退货运费
  - 非质量原因（尺寸不合适、颜色不喜欢等）：客户自付退货运费
- 处理时效：收到退货后 3–5 工作日完成退款，退回原支付方式

## 二、换货流程（五步）

| 步骤 | 动作 | 时效 |
|------|------|------|
| ① 申请 | 客户通过邮件/在线聊天联系客服，说明换货原因（尺寸/颜色） | 需在收货 30 天内发起 |
| ② 审核 | 客服核对订单号与产品照片，确认符合换货条件 | 1–2 工作日 |
| ③ 寄回 | 客服提供退货地址与标签；质量问题运费我司承担，非质量原因客户承担退货运费 | 客户 7 天内寄出为宜 |
| ④ 验收 | 仓库收到旧件并检查（未洗涤/未使用/原包装） | 收货后 1–2 工作日 |
| ⑤ 发出新件 | 库存充足前提下发出换货商品，换货发货免运费 | 验收后 1–2 工作日 |

- 换货期限：自收货起 30 天内
- 支持尺寸、颜色换货（库存充足前提下）

## 三、不支持退换货的情形

- 超过 30 天退货期
- 已洗涤、已使用（有明显使用痕迹）
- 人为损坏（撕裂、烧损、染色等）
- 床垫保护垫已拆封使用（卫生原因）
- 定制款（刺绣姓名、定制颜色）无质量问题时不支持退货

**客服话术要点**：遇到上述情形时明确告知不符合退换条件，同时可引导：180 天质量保证范围内的质量问题仍可处理（见第四节）；床垫保护垫未拆封可正常退。

## 四、质量保证政策（Quality Guarantee）

- 所有产品提供 **180 天质量保证**（自收货日起）
- 质量问题范围：缝线开裂、面料严重起球（非正常使用）、颜色大量脱落（非正常洗涤）、拉链损坏、填充物渗漏
- 质量问题处理：提供照片 → 客服审核 → 补发/退款，无需退回原产品（视情况）

注意区分：正常工艺误差（尺寸 ±2–3cm）、棉类首次缩水 3–5%、深色前 2–3 次轻微浮色属正常现象，不在质保范围（详见《05-洗涤护理指南》）。

## 五、亚马逊平台退货

- 遵循亚马逊平台退货政策（通常 30 天）
- 通过亚马逊退货中心（Return Center）发起退货申请
- Prime 会员享受免费退货

**客服提示**：亚马逊订单的退换货一律引导客户走亚马逊后台，独立站客服不直接办理退款；但质量问题赔偿、售后咨询仍由我们跟进。

## 六、退款方式与到账时间线

| 退款方式 | 处理时效 |
|---------|---------|
| 信用卡 / 借记卡 | 3–5 工作日到账 |
| PayPal | 1–3 工作日到账 |
| 礼品卡 / 积分 | 即时到账 |
| 银行转账 | 5–10 工作日 |

## 七、部分退款情形（补充）

以下情形可协商部分退款，金额以客服审核为准（示例区间，需主管确认）：

| 情形 | 参考方案 |
|------|---------|
| 轻微瑕疵但客户愿意保留产品 | 协商退还订单金额的 10–30% |
| 外包装破损但产品完好 | 协商 5–15% 补偿或补发配件 |
| 赠品缺失/损坏 | 补发赠品或等值小额补偿 |

**红线**：任何超出《12-投诉处理与赔偿标准》赔偿表的方案必须升级主管审批，客服不得自行承诺。

## 八、订单修改与取消

- 订单确认后 **1 小时内**可通过邮件联系客服修改（地址、颜色、尺寸）
- 已进入打包环节则无法修改，需待收货后走换货流程
- 未发货前可全额取消退款
- 已发货则需收货后申请退货，退货运费客户承担（非质量问题）

## 九、退换货申请材料清单

客户发起申请时，一次性收齐以下材料（避免反复索要拖慢时效）：

| 材料 | 何时需要 |
|------|---------|
| 订单号或注册邮箱 | 所有申请 |
| 问题照片（整体+细节特写） | 质量问题、错发、破损 |
| 外包装照片（含面单） | 破损、丢件、疑似调包 |
| 承运商追踪截图 | 延误、显示已投递未收到 |
| 测量数据 | 尺寸不符申诉 |

**审核时效承诺**：材料齐全后 1–2 工作日给出判定结果。

## 十、退货标签使用教程

1. 客服审核通过后，向客户邮箱发送预付退货标签（质量问题免费；非质量原因的标签费用从退款中扣除）
2. 打印标签并牢固贴在包裹外箱——**覆盖或撕除原面单**
3. 按标签指定承运商投递（USPS 网点/UPS 网点/预约上门取件）
4. 保留底单直到退款到账
5. 无打印条件的客户：部分承运商网点支持出示二维码直接打印

## 十一、退款失败排查手册

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 退款显示已处理但未到账 | 银行处理延迟 | 信用卡 3–5 工作日、PayPal 1–3 工作日（《07》第六节）；超期后引导客户联系发卡行并提供退款凭证号 |
| 原卡已注销/过期 | 发卡行拒收 | 客户联系银行恢复账户或转人工退款流程 |
| 只收到部分退款 | 运费扣减（非质量原因）或部分退款方案 | 核对退款明细说明 |
| BNPL 订单退款疑问 | 分期路径退款 | 见《08》第二节联动口径 |
| 礼品卡支付退款去向 | 原路退回礼品卡余额 | 即时到账，可在 My Account 查看 |

## 十二、质量问题判定细则

### 12.1 属于质量问题的情形

- 缝线开裂、脱线（非外力拉扯）
- 面料严重起球（正常洗涤数次内出现）
- 颜色大量脱落（按《05》正确方式洗涤后）
- 拉链损坏（无法使用/脱落）
- 填充物渗漏（羽绒结块外漏）
- 标称尺寸与实测偏差 >±5%
- 异味严重且水洗后不消（《05》第五节）

### 12.2 不属于质量问题的情形

- 正常工艺误差（±2–3cm 内）、棉类首次缩水 3–5%、深色前几次浮色
- 未按洗护指南导致的损坏（高温烘干缩水、氯漂褪色等）
- 主观手感/颜色偏好（显示器色差 ±5–10% 属告知范围）
- 人为损坏：撕裂、烧损、染色、宠物抓咬

### 12.3 判定流程

客户照片初审（质检专线）→ 存疑时要求补充视频或寄回实物检测 → 判定结果 + 依据条款回复。判定为质量问题的按《12》赔偿表执行；判定不属于的，客服解释依据并提供替代方案（如折扣复购码需主管批准）。

## 十三、换货库存不足的处理

目标款式缺货时的选项顺序：
1. **等补货**：登记客户联系方式，到货后优先发出（告知预计等待时长）
2. **换其他款式**：差价多退少补；升级款需客户补差价
3. **转为退款**：按原支付路径全额退款

不得未经确认擅自更换等价品发货。

## 十四、特殊场景退换货

### 14.1 礼物退货（无收据人）

- 收礼人想退：凭订单号或购买人邮箱辅助核实
- 退款去向：默认原路退回付款账户；礼品型需求可协商转为等额礼品卡（《09》第五节）
- 礼盒包装完好度影响判定

### 14.2 搬家/军人部署等特殊情况

- PCS（军人调动）/长期出差无法收货：未发货可全额取消；已发货按正常退货流程
- 不设"特殊身份免运费"例外——政策一致性优先

### 14.3 团购/多人拼单

- 多个订单分别独立计算退换期与运费门槛，不做合并处理

### 14.4 超长预售商品

- 预售页明示发货时间；超期未发可全额取消并获补偿码（示例：$10，主管审批）

## 十五、退换货欺诈防范（客服内部参考）

常见模式与应对：

| 模式 | 识别信号 | 应对 |
|------|---------|------|
| 掉包退货 | 寄回品与订单不符/旧货 | 开箱验货留影像；拒付并走平台申诉 |
| 穿用后退 | 明显使用痕迹、洗涤气味 | 按《07》第三节拒绝并解释条款 |
| 反复买退 | 同款多次购买退货 | 记录频次；超过阈值限制促销参与（主管审批） |
| 虚假未收到 | POD 显示本人签收但声称没收到 | 出示 POD 证据（《06》第十节）；坚持调查流程 |

**红线**：有怀疑可以查证，但不得在证据不足时指责客户欺诈。

## 十六、退款方式选择的边界

- 只能退回**原支付方式**——不支持"退款到别的卡/别人账户"
- 礼品卡支付的订单退款回礼品卡余额（即时）；该余额可申请转为新礼品卡转赠他人
- BNPL 见《08》第二节
- 原支付通道已失效（卡注销）：走《07》第十一节人工流程

## 十七、退换货政策对外沟通模板

### 模板 A：标准退货受理

> 您好，您的订单符合退货条件（《07》第一节：30 天内、未洗涤未使用、原包装）。
> 请提供以下信息，我们会在 1–2 个工作日内审核并发送退货标签：
> 1. 订单号
> 2. 退货原因（帮助我们改进）
> 温馨提示：非质量问题退货运费需您承担；质量问题全程免费。

### 模板 B：不符合退货条件的委婉拒绝

> 感谢您联系我们。很遗憾，根据我们的退货政策，该商品已超过 30 天退货期/已拆封使用，无法办理退货。
> 不过请放心：
> - 如果使用中出现了缝线开裂等质量问题，180 天质量保证依然有效（《07》第四节），欢迎随时申请。
> - 如对判定有疑问，可回复本邮件申请复核。

### 模板 C：换货流程告知

> 已为您登记换货申请。流程如下：
> ① 审核（1–2 工作日）→ ② 发送退货标签 → ③ 您寄回旧件 → ④ 仓库验收（1–2 工作日）→ ⑤ 新品发出并邮件追踪号。
> 全程进度可在 My Account → Returns 查看。

## 十八、退款争议升级路径

```text
客户质疑退款 → 一线核对时间线（《07》第六节时效表）
  ├─ 在时效内 → 解释 + 给出到账预计日
  ├─ 超时未到账 → 《07》第十一节排查手册逐项排查
  └─ 排查无果/客户仍不满 → 升级主管（24h 内响应）
```

**数据要求**：所有退款类工单必须附退款凭证号（Refund ID），无凭证号的工单视为未完成。

## 二十、退换货流程图（文字版）

```text
客户申请 → 客服审核(1-2工作日)
  ├─ 通过 → 发退货标签 → 客户寄回 → 仓库验收(1-2工作日)
  │     ├─ 合格 → 退款/换货执行
  │     └─ 不合格 → 拒绝并说明依据（附验收证据）
  └─ 不通过 → 解释条款 + 替代方案（质保/补偿码需审批）
```

**换货加速通道**：高价值订单（>$150）或会员等级 Silver 及以上，旧件寄出后即可先发新件（无需等验收）——示例政策，主管审批后使用。

## 廿一、部分退款情形速查表（客服判定用）

| 情形 | 退款比例 | 依据 |
|------|---------|------|
| 轻微外观瑕疵客户愿意保留 | 10–20%（示例，主管审批） | 《12》第三节精神 |
| 套装中单品质量问题 | 单品价格占比退款或补发单品 | 《07》第四节 |
| 运输轻微压痕不影响使用 | $5–$10 关怀补偿（示例） | 客户接受为前提 |
| 逾期未发货取消 | 全额 + $10 补偿码（示例） | 《07》第八节 |
| 尺寸超差 >±5% | 全额 + 免费退货标签 | 《12》第三节 |

**执行纪律**：所有比例类补偿必须留痕审批；同一订单不叠加多项补偿取最高一项。

## 廿二、退换货咨询快速分诊树（客服会话用）

```text
客户问"能退吗？"

└─ 只想要钱不想退货 → 部分退款情形表（廿一节）需审批
```
