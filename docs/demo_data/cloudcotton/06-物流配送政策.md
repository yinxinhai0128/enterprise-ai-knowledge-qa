## 四、订单处理时效

- 工作日下午 2 点（当地时间）前下单：当日处理
- 工作日下午 2 点后或周末下单：次工作日处理
- 定制订单（刺绣、定制颜色）：额外 3–5 工作日

## 五、物流追踪

- 发货后 24 小时内发送追踪号到注册邮箱
- 追踪链接：独立站 "My Account → Orders" 页面，或承运商官网直接查询
- 亚马逊订单：在亚马逊订单详情页查看
- 如 48 小时内未收到追踪信息，请联系客服

**常见问答**

Q：为什么我没有收到订单确认邮件？
A：请检查垃圾邮件文件夹；也可能邮箱地址填写有误，请联系客服提供订单号核实。

Q：可以寄送到 PO Box 吗？
A：USPS 可寄送 PO Box；UPS/FedEx 不支持 PO Box，请使用实际地址。

## 六、特殊情况处理

### 6.1 包裹丢失

物流显示"已投递"但客户未收到：
1. 先等待 3 个工作日（可能为延迟扫描）
2. 之后客服提交丢件调查
3. 确认丢失后补发或退款

### 6.2 包裹损坏

- 收件时请拍照记录
- 在签收后 48 小时内联系客服并提供照片
- 可申请补发配件或全额退款

### 6.3 海关扣押（跨境直发）

- 极少发生；如遇海关清关延误，客服协助提供必要文件
- 如被没收，全额退款

### 6.4 清关与关税说明（跨境直发场景）

- 跨境直发包裹可能产生进口关税/增值税，由买家承担（以各国海关规定为准）
- 本地仓发货（美国/英国/德国/澳洲/日本仓）订单价格已含税，无额外进口费用
- 客户询问清关进度时，客服可协助联系承运商查询，但不承诺清关时限

### 6.5 延误判定参考

- 包裹延误超 10 个工作日的补偿标准见《12-投诉处理与赔偿标准》赔偿表（$10–$20 礼品卡 + 继续追踪）
- 判定依据以承运商官方追踪记录为准，不按客户主观感受计算

## 八、地址问题与改派

### 8.1 地址相关场景

| 场景 | 政策 |
|------|------|
| 下单后 1 小时内改地址 | 邮件联系客服修改（《07》第八节） |
| 已发货改地址 | 尝试联系承运商改派；成功与否取决于承运商，产生费用由客户承担 |
| 地址错误已投递他人 | 属客户填写失误；可尝试承运商追回，失败则无法退款——下单前请核对地址 |
| 快递柜/代收点签收后丢失 | 视同已投递；建议选择安全收货方式 |

### 8.2 无人在家怎么办

- UPS/FedEx 默认尝试投递 3 次，之后存放在取件点（通常保留 5–7 天）
- 客户可通过承运商官网预约二次投递时间或改送取件点
- 超期未取被退回的包裹：按"客户原因退回"处理——重新发货需客户承担运费，或退款时扣除原始运费

## 九、物流异常排查手册（客服用）

| 现象 | 排查步骤 | 常见结论 |
|------|---------|---------|
| 追踪号无物流信息 | ①确认是否在发货 24h 内 ②查承运商官网 | 揽收扫描延迟 1–2 天属正常 |
| 物流信息停滞数天 | ①查途经节点 ②跨太平洋/大西洋段海上无扫描属正常 | 国际段 5–7 天无更新常见 |
| 显示"Delivered"但没收到 | 进入丢件流程（《06》第六节）：等 3 工作日→提交调查 | 可能被邻居代收/放错位置 |
| 包裹显示"Exception" | 读异常代码：地址问题/天气延误/清关中 | 对应第三节特殊情况处理 |
| 清关超过 7 天 | 收件人配合海关提供 ID 或税号 | 各国海关时限不同，客服协助文件 |

## 十、物流名词解释（对客沟通用）

| 名词 | 通俗解释 |
|------|---------|
| POD (Proof of Delivery) | 签收凭证：签收人签名/照片/GPS 记录，拒付争议时的核心证据（《08》第五节） |
| 揽收扫描 | 承运商第一次扫入系统，之后才能在官网追踪 |
| 尾程配送 | 到达目的国后的最后一段本地配送 |
| 清关 | 海关审核进境包裹（可能要求补充收件人身份信息） |
| Delay Scan | 延迟扫描：显示已投递但数据晚到的情况，等 3 工作日的依据 |

## 十一、承运商投诉与理赔

- 客户对配送服务不满（态度/暴力分拣/投递照片可疑）：客服记录后向承运商客户经理反馈
- 理赔申请：丢件与破损由我司向承运商发起理赔，客户无需自行操作
- 客户自行向承运商投诉不影响其向我司主张的售后权利

## 十二、运费边界场景补充

| 场景 | 政策 |
|------|------|
| 订单 $48.99 差 1 分钱免邮 | 不凑整——推荐加购小件（毛巾/枕套）过门槛，客服可主动提示 |

| 海外军事地址（APO/FPO） | USPS 渠道可达；时效另计，下单前咨询客服 |

## 十三、多包裹与分批发货

- 大件（被芯）与小件可能分仓发货——产生多个追踪号，均会邮件通知
- 分批到达属正常，客户误以为"丢了一件"时先核对追踪号数量
- 部分包裹丢失：只对丢失件走丢件流程（《06》第六节），不影响已签收部分

## 十四、签收注意事项（客户教育话术）

1. **当场验视**：外箱明显破损/浸水 → 当着配送员面开箱拍照
2. **48 小时窗口**：破损索赔需签收后 48 小时内联系客服并提供照片（《06》第六节）
3. **重量异常**：感觉过轻先别急着拆完，称重对比商品页标重
4. **代收风险**：让前台/邻居代收的，以代收时间为"收货之日"计算 30 天退货期

## 十五、物流数据口径（客服内部参考）

- "工作日"不含周六日与目的国法定假日
- 时效从"承运商揽收扫描"起算，不从下单时刻起算——处理时效与运输时效是两段
- 客户说"等了 10 天了"，第一步是拆解：下单→揽收几天 + 揽收→现在几天，再对照《06》第一、四节判定

## 十六、国际段运输科普（对客解释用）

### 16.1 一票跨境件的旅程

```text
下单 → 仓库拣包 → 揽收扫描 → 出口口岸 → 国际干线(海/空) → 进口清关 → 目的国分拨 → 尾程配送 → 签收
```

- 客户最焦虑的"没动静"阶段通常是国际干线（海上 5–7 天无扫描正常）
- 清关需要收件人配合时承运商会直接联系，客服可协助传递文件
- 本地仓订单无国际段，全程本地追踪

### 16.2 为什么不能承诺精确送达时刻

- 干线班次、清关队列、尾程排车都不在我司控制内
- 我们能承诺的：发货时效（处理）、参考时效区间、异常响应速度
- 客户要"精确到某天几点"：如实说明行业惯例，Express 是最接近确定性的选项

## 十七、物流类投诉的取证清单

| 投诉类型 | 需收集 |
|---------|--------|
| 延误 | 下单时间、揽收时间、当前节点截图 |
| 丢件 | POD 记录（签收人/照片/GPS）+ 客户口头陈述记录 |
| 破损 | 外箱六面照 + 内件破损特写 + 面单特写 |
| 错投地址 | 收货地址核对（订单 vs 实际投递地） |

证据齐全后按《12》第三节赔偿表执行；缺证据先补证再判定。
