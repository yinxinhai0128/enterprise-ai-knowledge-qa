# 04 · 材质详解与性能对比

> 本文档供客服与运营团队查询产品材质特性、认证背景与选购建议使用。客户咨询"哪种材质适合我""天丝和棉哪个好""羽绒会不会过敏"时依据本文档作答。

---

## 一、埃及长绒棉（Egyptian Long-staple Cotton）

- 纤维长度：≥36mm（特长绒）
- 特点：纱线纤细、手感顺滑如丝、光泽度好、耐洗耐用
- TC（Thread Count）：我司产品从 300TC 到 800TC，600TC 为旗舰款
- TC 说明：TC 越高并不绝对代表越好，同等纤维质量下 400–600TC 体验最佳
- 洗涤建议：冷水 / 温水（≤40°C），温和洗涤剂，避免漂白

**常见问答**
- Q：被套拉链在哪里？A：位于被套底部，长度覆盖开口 2/3 以上，方便套入被芯；拉链头有防脱落设计。
- Q：床单四角松紧带会松吗？A：采用四角全包松紧带（All-Around Elastic），深兜设计（15 英寸）可牢固固定；松脱属质量问题可联系客服。

## 二、竹纤维（Bamboo Fiber）

- 原料：毛竹（Moso Bamboo），不使用杀虫剂
- 工艺：机械法（Bamboo Linen，更环保）或化学法（Bamboo Viscose/Rayon）
- 特点：天然抗菌、透气性优于棉、吸湿排汗、适合敏感肌和过敏体质
- 重要说明：若为化学法竹粘胶（Viscose from Bamboo），在美国须在标签中标注 "Rayon made from Bamboo"，不可简称 "Bamboo"（FTC 合规要求）
- 适合人群：爱出汗者、过敏体质、热带或夏季使用

## 三、天丝 / 莱赛尔（Tencel / Lyocell）

- 来源：木浆（桉树），闭环溶剂工艺，99% 溶剂可回收，环保
- 特点：极度柔软（丝滑感）、吸湿快干、抑菌、悬垂性好
- Tencel 是 Lenzing AG 的注册商标，我司使用正版授权 Tencel 纤维
- 洗涤注意：30°C 以下冷洗，不可烘干（或低温烘干），不可拧绞

## 四、有机棉（Organic Cotton）

- 认证：GOTS（Global Organic Textile Standard），证书编号 CU12345678，可在 global-standard.org 官网核查
- 区别于普通棉：不使用农药、化肥、转基因种子，土壤健康追踪
- 特点：触感稍粗于埃及长绒棉，但更哑光、亲肤、适合婴儿及敏感肌
- 我司有机棉来源：印度古吉拉特邦认证农场

## 五、法兰绒（Flannel）

- 材质：100% 棉，经过拉绒工艺
- 重量（GSM）：我司法兰绒产品 170–200 GSM
- 特点：保暖性强、起毛柔软、适合秋冬
- 适合气候：北美、加拿大、北欧冬季
- 注意：首次洗涤可能有轻微掉色，属正常现象

## 六、羽绒填充物规格

| 指标 | 白鸭绒 | 白鹅绒 |
|------|--------|--------|
| 绒含量 | ≥90% | ≥90% |
| 蓬松度 | 550–600 FP | 600–800 FP |
| 清洁度 | ≥450mm | ≥500mm |
| 浊度 | ≥400mm | ≥450mm |
| 认证 | RDS（负责任羽绒标准） | RDS |

蓬松度（Fill Power）越高，保暖性越好且被子越轻。

**常见问答**
- Q：羽绒被会漏绒吗？A：优质羽绒被会有极少量羽绒透过面料，属正常现象；我司采用高密防绒面料（Downproof），正常使用漏绒极少。大量漏绒属质量问题，请联系客服。
- Q：羽绒被适合过敏人群吗？A：大多数羽绒过敏并非来自羽绒本身，而是尘螨。我司羽绒经过清洁处理（清洁度见上表）；如确为羽绒过敏，建议选购 Alternative Down 替代羽绒系列。

## 八、选购建议决策树

按客户描述的痛点依次判断：

1. **怕热/夜里出汗多** → 首选天丝凉感系列，其次竹风系列
2. **过敏体质/敏感肌/婴幼儿** → 首选有机棉系列（GOTS 认证），儿童选 Kids Cloud
3. **追求酒店级质感/送礼** → Cloud Luxe 云奢系列
4. **冬天怕冷/北方无暖气** → 法兰绒系列；被子选白鹅绒高蓬松度款
5. **预算有限又要体面** → Hotel Collection（自用亦可）
6. **养宠物/小孩尿床** → 床垫加防水款保护垫
7. **素食主义者/动物福利关注者** → Alternative Down 替代羽绒被

**客服话术要点**：先问睡眠环境（室温、是否出汗、过敏史）再推荐；引用对比表时同时说明"体验因人而异，收货后不满意可依据退换货政策处理"。

## 九、面料术语小词典（客服培训用）

| 术语 | 全称 | 含义 |
|------|------|------|
| TC | Thread Count | 每平方英寸经纬纱线总根数；300–800TC 区间，600TC 旗舰；非越高越好 |
| GSM | Grams per Square Meter | 每平方米克重，毛巾/法兰绒常用；700GSM 浴巾为厚实档 |
| FP | Fill Power | 蓬松度，羽绒每盎司占据体积（立方英寸）；越高越暖越轻 |
| Downproof | — | 高密防绒面料，阻止羽绒钻出 |
| All-Around Elastic | — | 四角全包松紧带（床单） |
| Deep Pocket | — | 深兜设计，适配加厚床垫 |
| RDS | Responsible Down Standard | 负责任羽绒标准，禁止活拔毛 |
| GOTS | Global Organic Textile Standard | 全球有机纺织品标准 |
| OEKO-TEX | STANDARD 100 | 纺织品有害物质检测认证 |
| Lyocell/Tencel | — | 莱赛尔纤维；Tencel 为 Lenzing 注册商标 |
| Viscose from Bamboo | — | 化学法竹粘胶纤维（美国标签规范用语） |

## 十、材质选购高频场景问答

### 10.1 场景问答集

Q：南方回南天/梅雨季买什么？
A：吸湿排汗优先——天丝凉感系列或竹风系列；避免法兰绒（保暖但闷）。存放注意防潮（《05》收纳节）。

Q：北方暖气房冬天盖什么？
A：白鹅绒被 Winter 款 + 法兰绒床品组合；鹅绒 600–800FP 锁温轻盈不压身。

Q：认床、皮肤敏感睡哪套？
A：有机棉系列（无化学残留、哑光亲肤）；搭配透气款保护垫。

Q：给老人选什么？
A：易打理优先——埃及棉系列（可机洗、中温烘干）；避免需要精细护理的材质。记忆棉枕对颈椎支撑好但不可水洗，需提前告知。

Q：宿舍学生党预算有限？
A：Hotel Collection 自用 + 纤维枕；Twin XL 尺寸注意确认。

### 10.2 认证核查教程

**OEKO-TEX 核查步骤**：
1. 打开 oeko-tex.com 官网 → Certification 查询
2. 输入证书编号 21.HIN.12345
3. 核对证书有效期与覆盖产品范围

**GOTS 核查步骤**：
1. 打开 global-standard.org → Certified Suppliers 数据库
2. 输入证书编号 CU12345678 或供应商名称
3. 显示认证实体、范围与有效期

客服遇到较真的客户时，直接给编号和官网路径，比口头保证更有说服力。

### 10.3 材质保养常见误区

| 误区 | 事实 |
|------|------|
| "TC 越高越好，所以买 800TC" | 同等纤维下 400–600TC 体验最佳；虚标 TC 反而可能是低质棉 |
| "柔顺剂让毛巾更蓬松" | 柔顺剂在纤维表面成膜，降低毛巾吸水性（《05》） |
| "羽绒被晒太阳杀菌" | 长时间暴晒加速面料老化与绒质脆化；通风阴干即可 |
| "所有床品都能熨" | 天丝/竹纤维只能低温（110°C），法兰绒不建议熨烫（《05》速查表） |
| "记忆棉枕拿去晒" | 记忆棉遇热老化变形；只可阴凉处通风 |

## 十一、材质类售后判定口径

- 材质成分与标注不符：重大质量问题 → 全额退款 + 免费退货标签（《12》）
- 正常范围内的手感差异、轻微色差、首次浮毛浮色：不属于质量问题，客服耐心解释文档依据
- 因错误洗涤导致的损坏：不属于质保范围；可引导按《05》正确方式重新护理尝试挽救

## 十六、材质工艺深度说明（较真客户应答储备）

### 16.1 为什么 600TC 是甜点区

- 纱线支数（60S/80S/100S）决定单根纱的细腻度，TC 是每平方英寸总纱线数
- 低质棉靠加密织造也能堆高 TC，但透气性差、手感闷
- 我司旗舰：80S 长绒棉纱 + 600TC 织造——细腻度与透气平衡
- 客户问"为什么不做 1000TC"：如实引用第一节 TC 说明——同等纤维质量下 400–600TC 体验最佳

### 16.2 竹纤维两种工艺的差异

| 工艺 | 过程 | 特点 |
|------|------|------|
| 机械法（Bamboo Linen） | 物理脱胶成麻状 | 环保但手感偏硬，市面少见 |
| 化学法（Viscose） | 竹浆溶解再生纤维素 | 柔软垂坠；美国标签须标 "Rayon made from Bamboo" |

我司竹风系列为混纺（60% 竹 40% 棉），兼顾柔软与棉的挺括。

### 16.3 天丝闭环工艺的意义

- 溶剂（NMMO）回收率 99%——不是"零排放"而是"循环使用"
- 原料为认证种植林的桉木浆
- 客户从环保角度追问时，可引导至《01》可持续发展章节整体口径

### 18.2 羽绒 vs 纤维被的诚实建议

| 客户情况 | 推荐 |
|---------|------|
| 追求轻盈保暖、预算充足 | 白鹅绒 |
| 羽毛过敏体质 | 纤维填充被（无过敏原） |

### 18.3 记忆棉枕与羽绒枕的使用寿命

- 记忆棉枕：3–5 年更换；回弹明显下降或发黄变硬即到期
- 羽绒枕：每 1–2 年晾晒翻新，蓬松维持良好可用 5 年以上
- 客户问"多久换枕头"：以上述实际状态为准，年限只是参考
